# Face Lock System

A Python based 2D face detection and recognition lock system.

## Features
- 2D face detection
- Face recognition using Python
- Camera based face scanning

## Requirements
- Python 3.11.x
- OpenCV
- face_recognition
- numpy
- os
- threading
- pyttsx3 (if you need speak function.)

## Setup
1. Install required libraries.
2. Add your own face image path in the program.
3. Run the Python file.

## How to Run

python face_lock.py
